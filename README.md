# 《吉星派对》随机挑战

当前版本：**v1.3.0** · [更新日志](CHANGELOG.md)

随机抽取角色、地图与不重复的四人队伍。保留原来的四条命令，增加图鉴自动同步、管理员手动同步与数据状态查询。

## 定位组合抽取

在队伍或随机开局命令后添加组合即可：

| 命令 | 作用 |
| --- | --- |
| `/星趴队伍 2辅2c` | 两个辅助位、两个输出位 |
| `/星趴随机 2辅2c` | 默认合作地图，加两辅助两输出队伍 |
| `/星趴随机 合作 1辅3c` | 合作地图，加一辅助三输出队伍 |
| `/星趴随机 1辅1坦2c` | 一辅助、一生存、两输出 |
| `/星趴队伍 4c` | 四个输出位 |
| `/星趴队伍 1辅3任` | 一辅助，其余三个自由位 |
| `/星趴队伍 2攻2卡` | 两个攻击输出位、两个卡牌输出位 |

`C/c/输出`、`辅/辅助/奶`、`坦/T/生存`、`任/任意/自由`均可识别；人数合计必须为四人。例如 `2辅助2C`、`2辅2c` 等价。模式与组合可交换顺序，推荐将组合写成一个连续参数。无组合参数时保持原来的全角色随机抽取。

图片会显示“阵容 2辅2C”，各位置标注“辅助／输出”等定位；文字回退也会标注。全队仍保证不同角色，每个角色固定一个主定位，不会为了凑阵容临时从辅助变成输出。

当前 35 名角色已在 `data/catalog.json` 的 `roles` 中固定主定位。其中远野汉娜（汉娜）、恋固定为辅助，梅加斯固定为卡牌输出（C）；“C”池合并攻击型与卡牌型。职业分值只作分类参考，不再因分值并列让角色同时进入辅助和输出池。这是合作随机配队的约定定位，不表示所有流派的最优打法。

自动同步会更新职业分值，但保留已确认的主定位。旧缓存缺少定位时优先使用内置定位表。未知新角色有职业分值时首次按最高分估算一个定位，并列时按辅助、攻击、卡牌、生存的固定顺序选择；该估算随后保留，不会随每次同步分值改变。尚无分值的新角色只参与普通随机和自由位，待维护者确认后补充定位。

维护者可在角色 JSON 条目中设置单元素 `roles` 列表：`support`（辅助）、`attack`（攻击输出）、`card`（卡牌输出）、`damage`（不区分类型的输出）、`tank`（生存）。例如 `"roles": ["support"]`、`"roles": ["card"]`；`[]` 表示暂不分类。兼容旧版多标签列表时只采用第一个有效定位，不再跨位兼任。手工定位会在自动同步时保留；修改角色定位请同步修改内置或缓存中的 `roles`。基础 `role_scores` 四项顺序仍为攻击、卡牌、辅助、生存。

## 图片输出

四条抽取命令默认发送带头像的粉白色图片：粉色标题栏、地图与玩法信息、按一至四号位排列的角色卡片。单抽、只抽地图会使用相应的紧凑版式。没有实际配置的难度或预设不会凭空显示。

无参数时固定抽取合作地图；所有模式均过滤未开放、已结束及开放时间不明的限时地图。图片中的队伍信息显示人数，指定组合时额外显示阵容与定位。

![图片输出预览](docs/preview.png)

优先使用 Pillow 在本地生成 PNG，不需要浏览器或外部渲染服务；绘图和头像文件读取在后台线程中执行。当前 35 名角色的高清游戏头像随插件分发，绘制时圆形裁切，无需在线下载。

本地自动查找 Windows 微软雅黑、Linux Noto CJK / 文泉驿或 macOS 苹方。AstrBot 官方 Docker 镜像包含 Noto CJK。其他 Linux 环境可安装 `fonts-noto-cjk`，或在插件配置的 `font_path` 填写已有中文字体文件路径。字体不可用时尝试 AstrBot 已配置的 HTML 渲染服务；生成或平台发送失败会回退成同一次抽取的文字结果，不会重新抽取。成功发送后清理本次生成的临时 PNG。

可在插件配置关闭 `image_output` 恢复文字输出。未来新角色会从图鉴卡片同步头像地址，首次使用时下载并缓存；无法取得头像时显示姓名占位，抽取仍正常进行。头像下载仅接受 BWIKI 图片域名，超时 6 秒、最大 1 MiB，并限制并发与失败重试频率。

## 使用

| 命令 | 作用 |
| --- | --- |
| `/星趴角色` | 抽取一名已上线角色，显示称号和姓名 |
| `/星趴队伍 [组合]` | 抽取四名不同角色，可指定如 `2辅2c` |
| `/星趴地图` | 抽取合作地图，含已确认开放的限时合作地图 |
| `/星趴地图 对战` | 明确指定后抽取对战地图 |
| `/星趴地图 限时` | 只抽已确认处于开放时间内的限时地图 |
| `/星趴地图 全部` | 所有当前可抽地图，包含对战，仍过滤未开放限时地图 |
| `/星趴随机 [合作/对战/限时/全部] [组合]` | 地图与四人队伍一起抽取 |
| `/星趴数据` | 查看来源、数据时间与数量 |
| `/星趴更新` | 仅 AstrBot 管理员：立即同步图鉴 |
| `/星趴帮助` | 查看命令 |

指令前缀遵循 AstrBot 设置。`/星趴随机` 和 `/星趴地图` 无参数时固定抽合作地图，不再受旧版默认模式配置影响。对战地图必须明确指定“对战”或“全部”才会参与。联动角色可能已无法获取，但已持有者仍可使用，因此保留在角色池。角色不会重复；无组合模式下地图与角色等概率抽取，指定组合时从合法定位分配中随机抽取；不检查玩家是否拥有角色。

## 安装与配置

Python 3.10+、AstrBot 4.x（需要支持 `AstrBotConfig` 和 `StarTools.get_data_dir`）、Pillow 11.2.1+。AstrBot 安装插件时会处理 `requirements.txt`；手动复制时请安装其中依赖。

项目地址：`https://github.com/shangzhimingge/astrbot_plugin_astralparty`。在 AstrBot 插件管理中通过此 Git 链接安装，或通过插件商店安装。升级现有安装前先备份原目录，避免同时安装两个同名插件。

将整个插件目录放入 AstrBot 的 `data/plugins/astrbot_plugin_astralparty`，随后重载插件。升级时请复制整个目录，包含 `card_renderer.py`、`cards.py`、`templates/` 和 `data/avatars/` 等新增文件。

插件配置面板：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `image_output` | `true` | 图片展示抽取结果，关闭后使用文字 |
| `font_path` | 空 | 自动查找中文字体，也可填写已有字体文件路径 |
| `auto_update` | `true` | 加载后后台同步，不阻塞抽取 |
| `update_interval_hours` | `24` | 自动同步间隔，支持 1–720 小时 |

同步直接读取国内 BWIKI，无需 GitHub Token，不下载或执行远程 Python。每次读取角色、地图图鉴，并尝试读取职业分值表；单次请求超时 15 秒、响应最大 4 MiB。姓名/ID/时间/模式会校验；角色缺失、地图数量减少、网络故障、解析失败或写入失败时保留旧数据。地图分组按图鉴导航表同步，不推断当期匹配轮换或限时活动开放状态。

成功后原子写入 AstrBot 工作目录下的 `data/plugin_data/astrbot_plugin_astralparty/catalog.json`，重启后继续使用。缓存损坏时回退到内置快照。新版本的内置快照若比缓存新，会优先使用内置快照。自动同步失败后按正常间隔重试，也可发送 `/星趴更新`。卸载插件会取消后台任务。

角色按图鉴上线时间（北京时间）过滤；只有图鉴提供了正确时间才会自动解锁。未来角色可能先被收录，但未到上线时间不会进入抽取池。

限时地图仅保留资料不会自动进入抽取池。需在地图条目中配置 `play_mode`（`pve` 或 `pvp`）、`available_from`、`available_until`（均为北京时间 `YYYYMMDDHHMM`），才会按开放时段加入对应玩法；开始时间包含，结束时间不包含，结束后自动退出。缺少起止时间的限时地图默认不可抽。目前内置 6 张限时地图均未配置开放时段，因此不会被抽中。图鉴导航表不能可靠说明活动是否开放，自动同步不会仅凭地图存在就将其开放；已确认的时段会保留。维护者确认复刻后更新 JSON 时段即可。

## 以后怎样更新

正常情况无需改代码：等待定时同步，或发送 `/星趴更新`。

维护者更新随插件发布的离线快照：

```bash
python scripts/update_catalog.py
```

提交生成的 `data/catalog.json` 即可，不需要修改 Python 枚举。脚本复用运行时的完整性校验，失败时不覆盖原文件。服务器不能访问 BWIKI 时，可在能访问的电脑运行脚本，然后复制快照。

图鉴尚未更新时，也可以编辑 `data/catalog.json`：
- 角色条目：`id`（唯一字符串）、`name`、`title`、`release_at`（北京时间 `YYYYMMDDHHMM`）。
- 地图条目：`id`（唯一字符串）、`name`、`mode`（`pve` / `pvp` / `limited`）。
- 限时地图开放时段：`play_mode`、`available_from`、`available_until`，未配置时默认排除。
- 保持 `schema_version: 1`，将 `synced_at` 改为当前带时区的 ISO 时间。

手工维护后关闭自动同步，并重载插件。若旧缓存时间更新，可备份并移走缓存文件，强制使用内置快照；重新开启自动同步后，数据以图鉴为准。删除角色或地图需手工核查，不会由自动同步静默执行。
